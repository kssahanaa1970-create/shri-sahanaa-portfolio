# Shri Sahanaa K S — Personal Portfolio

A full-stack personal portfolio website built with HTML, CSS, JavaScript, Node.js, Express.js and MongoDB.

## Features
- Responsive portfolio layout
- About and skills sections
- Projects section that honestly shows projects are coming soon
- Contact form
- Express.js backend API
- MongoDB message storage
- Ready for deployment

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Copy `.env.example` to `.env`.
5. Add your MongoDB connection string to `.env`.
6. Run `npm start`.
7. Open `http://localhost:3000`.

## Deployment
Deploy the Node/Express application on a service that supports Node.js and add `MONGODB_URI` as an environment variable.
